# Mock Reference Data

`synthetic_land_records.csv` contains synthetic prototype land-record rows for local validation and database seeding. These are not actual government records.

`upbhulekh_digitization_statistics.csv` is a separate dataset for source-derived/publicly visible digitization statistics. It is not individual owner or khasra data and is not loaded into `ReferenceRecord`.

Neither dataset represents an authorized government land-record database. Any production integration with government APIs or records requires authorization.
